# Local independent research compiler

Read-only copy of the server's existing stable Rust compiler and already built
release link dependencies, used inside the existing local Ubuntu environment.
No packages installed, no compiler or job changed on the server. Keep the large
runtime outside Git; preserve archive and member hashes, extraction verification,
version and local compile/test logs. One local compute/build core at a time.
This research runtime is never part of a candidate submission or official scorer.
