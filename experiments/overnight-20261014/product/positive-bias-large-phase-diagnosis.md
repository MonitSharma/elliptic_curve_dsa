This is a component result, with no point-addition qualification or score.

At width 128 / SQ_A_POLICY, the same prototype returned correct final quantum/classical values but failed the native phase assertion. The symbolic kernel reported 41 nonzero phase terms; the first term was measurement variable 3862 with coefficient all 64 input lanes. Width 129 was not reached. The [failed source receipt](positive-bias-large-phase-failed-receipt.json) and [patch](positive-bias-large-phase-failed.patch) preserve this failed experiment independently of the correction.

The [source-bound measurement map](positive-bias-measurement-map-receipt.json) completed exit 0 in the same failed source. The original producer cross had offset 4, so cross2_erase and cross2_restore each flip bit 2 under ROW0_COPY. The new uniform +2 identity instead gives exact retained cross 2ab, with offset zero. The old erase flip therefore introduces an uncancelled measurement-dependent phase even when final basis values are clean.

The separate cross2 variant removes only these two obsolete X flips. It retains HIGH_EARLY_LOAN=3, GO_B1/B2, phase repairs, cleanup, and every other installed recipe flag.
