# Uniform-rank phase-pebble chunk planning model

Specified-family analytic DP only. It combines retained boundary storage,
ordinary chunk comparisons and internal phase-pebble drops. For50 bits and
uniform rank1, carry budget8 has model expected75T and budget9 has70T. These
are component cost models; no such plan has been installed or measured.

A source-specific weighted planner must account for actual affine rows,
operand aliases, fixed core storage and all callback contracts, then pass
native phase/ancilla tests and the complete benchmark. This report is not a
point-add resource result or a lower bound over arbitrary circuits.
